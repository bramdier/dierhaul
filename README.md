# Dierhaul — Logistics Platform

A static Next.js marketing site for cargo management.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

`npm run build` writes the static site to `out/`.

## Routes

| Route | Module |
|-------|--------|
| `/` | Landing page |
| `/track` | Air waybill and express shipment forms |
| `/calculator` | Redirects to `/track` |
| `/project` | Project highlights |
| `/about` | About Us — Abraham Dier Spiez |
