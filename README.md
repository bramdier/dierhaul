# Dierhaul — One-Stop Logistics Platform

A Next.js application for unified logistics operations:

- **CTMS** — Container Tracking Management System
- **Fleet Tracking** — Real-time vehicle and asset monitoring
- **Pricing Calculator** — Cargo freight cost estimation with risk scoring

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Route | Module |
|-------|--------|
| `/` | Landing page |
| `/ctms` | Container Tracking Management System |
| `/fleet` | Fleet Tracking Management System |
| `/calculator` | Cargo Pricing Calculator |
| `/about` | About Us — Abraham Dier Spiez |
